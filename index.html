01 / Features

What you can do

  1. 01

    Subjects and lectures

    Make a subject for each class. Import lecture PDFs into it. A date is optional.

  2. 02

    Annotate pages

    Add text boxes. Draw freehand ink for diagrams with a mouse, touch, or stylus. Undo and redo your edits during a session.

  3. 03

    A notepad for each lecture

    Each lecture has its own notes. The notepad saves as you type.

  4. 04

    Search

    Find text in subject names, lecture titles, notepads, text boxes, and the PDF text itself.

  5. 05

    Export

    Save a lecture as a PDF with your annotations drawn on its pages. Any PDF viewer can open it.

  6. 06

    Planner and tasks

    Place a subject card in a time slot on the weekly planner. Move tasks through To do, Doing, and Done.

Open data. Your library is a folder of plain files. You can read them without the app.

02 / AI assistant

Connect an AI assistant

An AI assistant that supports MCP can read your material and help you study. It can create and edit. It cannot delete. Only you can delete, in the app.

  1. 1

    Install Node.js 22 or newer.

  2. 2

    Download betternotez-mcp.mjs from the latest release. Save it in a folder you will keep.

  3. 3

    Add this to claude_desktop_config.json. Replace the path with the full path to the file. Then restart Claude Desktop.

claude_desktop_config.json 
{
  "mcpServers": {
    "betternotez": {
      "command": "node",
      "args": ["/absolute/path/to/betternotez-mcp.mjs"]
    }
  }
}

For Claude Code, run this once in a terminal:

Terminal 
claude mcp add betternotez -- node /absolute/path/to/betternotez-mcp.mjs

Replace /absolute/path/to/betternotez-mcp.mjs with the full path to the file. The desktop app's Settings page shows both snippets with your library path filled in.

The server reads the BetterNotez Library folder in your home folder. To use another folder, add "--library" and the folder path to the arguments.

ChatGPT and other apps that support MCP servers can connect too. Their steps differ, so follow each app's own instructions.
